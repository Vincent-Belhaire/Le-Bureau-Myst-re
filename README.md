# Le Bureau Mystère — séance TICE 6e

Mini-site autonome pour une séance de 55 minutes. Aucune bibliothèque, connexion ou donnée personnelle n’est nécessaire.

## Tester sur son ordinateur

Ouvrir `index.html` dans un navigateur récent. Les trois fichiers `index.html`, `style.css` et `script.js` doivent rester dans le même dossier.

## Mettre en ligne avec GitHub Pages

1. Créer un dépôt GitHub public ou privé selon votre formule.
2. Déposer `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**.
4. Sélectionner la branche `main`, le dossier `/ (root)`, puis enregistrer.
5. Après quelques minutes, ouvrir l’adresse indiquée par GitHub Pages.

## Déroulé conseillé

- 5 min : accueil et consigne ;
- 10 min : défi 1, repérer les zones puis expliquer leur rôle ;
- 15 min : défi 2, manipuler les fenêtres puis résoudre quatre incidents ;
- 15 min : défi 3, maîtriser les gestes de souris puis choisir le bon geste dans six situations ;
- 5 min : bonus clavier, raccourcis puis saisie exacte ;
- 5 min : bilan, verbalisation et rangement.

Chaque grand défi comporte deux manches : une manipulation et un réinvestissement. Le score maximal est de 4 000 points, répartis également entre repérage, fenêtres, souris et clavier. Les aides ne retirent aucun point afin de valoriser le recours méthodique aux tutoriels.
